# Tema 2: Tipos de datos y variables

En este tema se estudian los tipos de datos primitivos de Python: enteros, flotantes, cadenas y booleanos. Se explican variables, conversión de tipos y la importancia de los identificadores.

**Ejemplo:**
```python
x = 10
texto = "Hola"
print(type(x), type(texto))
```

> **Nota:** Se acompaña siempre de la explicación en clase.
