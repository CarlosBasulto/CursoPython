
# Curso de Introducción a Python

Este repositorio contiene los materiales de los **8 primeros temas** del curso de Python.
Cada tema cuenta con su propio `README.md` con explicaciones, ejemplos y ejercicios.
El contenido está diseñado para ser utilizado **de la mano del profesor**, 
que guiará con explicaciones adicionales y ejemplos en clase.

---

## 📚 Contenidos de los Temas

### Tema 1 — Introducción a Python
Conceptos básicos del lenguaje, primeros pasos, instalación del entorno y uso del intérprete.

### Tema 2 — Variables y Tipos de Datos
Uso de variables, constantes y principales tipos de datos (enteros, flotantes, cadenas, booleanos).

### Tema 3 — Programación Básica
Estructuras de control (`if`, `while`, `for`), operadores lógicos y aritméticos, y ejemplos de algoritmos básicos.

### Tema 4 — Funciones
Definición de funciones, parámetros, argumentos, valores de retorno, funciones anónimas (`lambda`) 
y funciones incluidas en Python.

### Tema 5 — Organización del Código
Uso de módulos y paquetes, documentación, e introducción a la Programación Orientada a Objetos (POO) 
con clases, objetos, atributos, métodos y herencia.

### Tema 6 — Sentencias Avanzadas
Expresiones regulares, gestión de errores y excepciones con `try-except`, 
y comprensión de listas, diccionarios y conjuntos.

### Tema 7 — Análisis de Datos con NumPy y Pandas
Introducción a las librerías **NumPy** y **Pandas**, arrays, matrices, series y dataframes, 
operaciones estadísticas y manipulación de datos.

### Tema 8 — Visualización de Datos
Uso de **Matplotlib** y **Plotly** para generar gráficas de líneas, barras, histogramas, 
diagramas circulares y visualizaciones interactivas.

---

## 🎯 Objetivo
El objetivo del curso es que el alumno adquiera una base sólida de programación en Python, 
que le permita abordar proyectos más complejos en análisis de datos, desarrollo web o aplicaciones avanzadas.

---

## 🚀 Cómo usar este repositorio
1. Navega por cada carpeta `TemaX`.
2. Lee el `README.md` correspondiente con las explicaciones y ejemplos.
3. Resuelve los ejercicios propuestos en clase o en los comentarios del código.
4. Pregunta siempre al profesor si algo no queda claro.

---

## 📌 Nota importante
Este material **no sustituye** a las explicaciones del profesor. 
Es un apoyo de estudio que se debe trabajar en conjunto con las clases prácticas.
