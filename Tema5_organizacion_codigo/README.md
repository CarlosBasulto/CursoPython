# Tema 5: Módulos, paquetes y POO

Se enseña cómo organizar proyectos con **módulos** y **paquetes**, además de una introducción a la Programación Orientada a Objetos (POO): clases, atributos, métodos y herencia.

**Ejemplo:**
```python
class Persona:
    def __init__(self, nombre):
        self.nombre = nombre

    def saludar(self):
        print("Hola, soy", self.nombre)

p = Persona("Ana")
p.saludar()
```

> **Nota:** Se complementa con prácticas y explicaciones en clase.
