# Tema 3: Operadores y estructuras básicas

Aquí se presentan los operadores aritméticos, relacionales y lógicos, así como las estructuras de control `if`, `for` y `while`. Es la base de la programación estructurada.

**Ejemplo:**
```python
for i in range(5):
    if i % 2 == 0:
        print(i, "es par")
```
