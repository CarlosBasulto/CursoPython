# Tema 4: Funciones

El tema aborda cómo definir y usar funciones en Python, parámetros, valores de retorno y el concepto de ámbito. También se introduce la recursividad.

**Ejemplo:**
```python
def cuadrado(n):
    return n ** 2

print(cuadrado(4))
```
